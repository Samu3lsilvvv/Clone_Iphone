# Landing Page - iPhone 16 Pro

Este projeto é uma **Landing Page inspirada no site da Apple**, desenvolvida com **HTML, CSS e JavaScript puro**, com foco em layout moderno, responsividade e interatividade.

A página apresenta o produto **iPhone 16 Pro**, com navegação superior, seção principal com descrição do produto, seletor de cores dinâmico e rodapé estruturado em colunas.

---

## Demonstração

Projeto desenvolvido para fins educacionais e prática de:

- Estruturação semântica com HTML5
- Estilização moderna com CSS3
- Manipulação do DOM com JavaScript
- Responsividade com Media Queries
- Experiência do usuário (UX) com micro interações

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

Sem uso de frameworks ou bibliotecas externas.

---

## Funcionalidades

###  Seletor de cores interativo
Ao clicar em uma das cores disponíveis:
- A imagem do produto é alterada dinamicamente
- A cor selecionada recebe destaque visual
- É aplicada uma animação suave de transição


## Layout Responsivo

O projeto se adapta a telas menores (até 480px), ajustando:

- Navbar simplificada  
- Botões visíveis apenas quando necessário  
- Ajustes de tipografia  
- Footer reorganizado
